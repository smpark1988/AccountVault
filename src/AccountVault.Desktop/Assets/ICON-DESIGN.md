# AccountVault icon

The cobalt-blue safe and pale vault door match the app's blue accent and convey local encrypted storage. The central keyhole stays prominent at small sizes. The PNG retains the original transparent background.

- Generator: built-in ImageGen tool.
- Source: `AccountVault.png`.
- Windows icon: `AccountVault.ico`, containing 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel frames.
- Applied to the executable, every desktop window, and the setup and login screens.
- To regenerate the ICO from the PNG, run `./tools/Convert-AppIcon.ps1` from the repository root on Windows.

## Generation prompt

Create one premium, restrained Fluent-style app icon on a genuinely transparent alpha background, square 1024x1024 canvas. Subject: a bold cobalt-blue rounded-square vault body, with a clean inset pale silver/white rounded-square vault door and one centered deep-blue keyhole (a large circular head and short tapered stem) as the unmistakable focal point. Two subtle chunky hinges along the door's left edge convey a physical safe. Use the existing application's blue palette #2563EB, #1D4ED8, pale blue #EAF1FF and white. Mostly front-facing, almost flat with delicate bevels and very restrained dimensional depth, a soft top-left highlight, no dramatic perspective. Strong balanced silhouette and generous simple shapes must remain recognizable at 16x16 and 32x32. The outer rounded-square safe fills approximately 88% of the canvas, centered with even transparent padding, and all elements are contained inside that silhouette. Crisp beautifully antialiased contours, polished native Windows utility aesthetic, quiet and trustworthy. No text, letters, numbers, wordmark, watermark, extra objects, surrounding scene, decorative particles, padlock shackle, multiple icons, icon sheet, mockup, white backdrop or baked checkerboard. Render only the finished icon with actual transparency outside the rounded silhouette.
